# Manual breve

El administrador puede registrar tutores, pacientes, atenciones, consultar stock y cobrar cuentas. El superadministrador añade servicios, costos y control financiero, usuarios, configuración y auditoría.

Flujo recomendado: crear tutor, crear paciente, abrir una atención, registrar la información clínica, finalizarla, agregar servicios a su cuenta y registrar pagos hasta completar el saldo. Los pagos son registros manuales y no confirman operaciones bancarias.

Las atenciones finalizadas conservan su historia; las precisiones posteriores se agregan como aclaraciones fechadas. Nunca use una gratuidad para ocultar deuda ni una merma para representar un servicio gratuito.
